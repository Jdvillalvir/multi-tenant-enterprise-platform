# Contributing

1. Cree una rama descriptiva.
2. No agregue secretos.
3. Ejecute `npm run lint`, `npm run typecheck` y `npm test`.
4. Para cambios de seguridad agregue una prueba de regresión.
5. Para cambios de esquema incluya una migración Prisma.
6. Describa impacto y estrategia de despliegue en el PR.
